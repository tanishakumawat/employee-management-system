# Employee Management System

A responsive Employee Management System built with React and Tailwind CSS. The application allows users to manage employee records through CRUD operations and provides search, filtering, sorting, and pagination.

## Features

- View employee records in a responsive table.
- Add new employees with form validation.
- Edit existing employee details.
- Delete employees with confirmation.
- Search by employee name, role, or email.
- Filter by department and employment status.
- Sort employee records by name and role.
- Persist employee data using browser LocalStorage.
- Export filtered employee records to CSV.
- View employee statistics.
- Responsive dashboard layout for desktop and mobile.

## Tech Stack

- React
- Vite
- Tailwind CSS
- Lucide React
- JavaScript
- Browser LocalStorage

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository.
2. Open the project directory.
3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

5. Open the local URL displayed in the terminal.

## Data Storage

This project uses a predefined JavaScript employee dataset and browser LocalStorage. It does not require a backend or database.
